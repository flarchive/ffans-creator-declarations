## 🚀 v0.2.2 发布

本次更新改进了创作者声明的展示效果，优化了接口数据加载，并修复了与标签弹窗的冲突。

### ✨ 功能与体验改进

- 重新设计“原创”“转载”“参考或引用”三种内容来源声明的展示方式。 
  - 当帖子仅选择内容来源声明时，以独立提示形式展示；同时选择其他类型时，则统一显示在声明摘要中。
- 为“原创内容”“参考或引用内容”和“个人观点”提供更清晰的摘要文案。
- 调整声明摘要的布局。
- 优化编辑器顶部的声明按钮样式。

### 🐛 问题修复

- 修复打开编辑器后，立即选择声明后无法打开标签弹窗的问题。
- 修复回复主题时默认焦点没有在文本输入框内的问题。

### ⚡ 性能优化

- 减少接口中不必要的声明关系加载，降低无关页面的查询与响应开销。
- 设置独立的 Webpack 前端模块命名空间，避免与其他扩展的模块发生冲突。

### 📦 更新

```sh
composer update ffans/creator-declarations
php flarum migrate
php flarum cache:clear
```
