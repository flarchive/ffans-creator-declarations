## 🚀 v0.2.2 Released

This release improves the presentation of creator declarations, optimizes API data loading, and fixes a conflict with the tag selection modal.

### ✨ Features and UX Improvements

- Redesigned the presentation of the Original, Reposted, and Referenced or Quoted content source declarations.
  - When a post contains only a content source declaration, it is shown as a standalone notice. When other declaration types are also selected, all declarations are shown together in the declaration summary.
- Added clearer summary text for Original Content, Referenced or Quoted Content, and Personal Opinions.
- Improved the declaration summary layout.
- Refined the declaration button styling in the composer header.

### 🐛 Bug Fixes

- Fixed an issue where the tag selection modal could not be opened after selecting declarations immediately after opening the composer.
- Fixed the text editor not receiving focus by default when replying to a discussion.

### ⚡ Performance Improvements

- Reduced unnecessary declaration relationship loading in API requests, lowering query and response overhead on unrelated pages.
- Dedicated Webpack modules namespace to prevent conflicts with modules from other extensions.

### 📦 Updating

```sh
composer update ffans/creator-declarations
php flarum migrate
php flarum cache:clear
```

If you encounter any issues, please report them via the project repository or community forum.
